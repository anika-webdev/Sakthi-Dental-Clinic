# Sakthi Dental Clinic — ShadowFox Website

Updated using the client-provided image assets supplied in the ShadowFox brief.

## Included
- Home, About Us, Treatments, Contact, Privacy Policy
- All 15 treatment images
- All 3 clinic banner images
- All 5 clinic facility icons
- Client-provided Sakthi Dental Clinic logo
- Responsive lavender/white/pastel UI
- Mobile navigation
- FAQ accordion
- Testimonial slider
- Contact-form frontend validation
- SEO title and description tags

## Run
Open the folder in VS Code. If Live Server is installed, right-click `index.html` → **Open with Live Server**.
You can also open `index.html` directly in a browser.

## Note
The contact form currently performs frontend validation/demo handling only. It does not send data to a live email/database without a backend or form service.
